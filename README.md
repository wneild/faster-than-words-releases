# Faster Than Words

Highlight text in any app and hear it read aloud at up to 3x speed, with live captions.

Get it from **[fasterthanwords.com](https://fasterthanwords.com)**, which picks the right download for your computer. This repository only holds the release files: see [Releases](https://github.com/wneild/faster-than-words-releases/releases) for every version. Each release also includes `third-party-sources.tar.gz`, the source code of the open-source components it bundles.

Questions: support@fasterthanwords.com
